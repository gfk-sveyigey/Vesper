# 本地弹幕

播放界面 → 弹幕设置 → 导入本地弹幕文件，选择 Bilibili XML。

- 支持模式 1/2/3（滚动）、4（底部）、5（顶部），忽略高级/代码弹幕。
- 文件最多 16 MB、50000 条；单条文字最多 500 字符。不解析外部实体。
- 弹幕保存在当前播放会话内，不上传、不持久保存。切换媒体清空，切换引擎保留。
- 字号、透明度和显示开关为全局偏好；时间偏移仅用于当前媒体，正数表示延后。
- App Canvas 使用播放器时间绘制，与两个引擎无关。轨道满时丢弃新弹幕，避免重叠。
- 画中画不显示弹幕；未修改引擎依赖或系统画中画渲染。

Linux 可运行 `BuildSupport/tests/test_danmaku.py` 验证 XML 解析及大小限制。
显示、拖动进度、切换视频及文件选择器仍需 iOS 编译与真机验证。

## 自定义弹幕 API

在设置 → 弹幕设置 → 自定义弹幕 API 中添加、编辑、启停或删除服务。
仅支持 HTTPS 的弹弹play兼容服务，不是任意 JSON API。需手动填写名称和 API 基础地址。
基础地址可为 `https://dm.syemby.com/shunyingdm`，也可带 `/api/v2`；保留路径前缀。

播放界面 → 弹幕设置 → 搜索在线弹幕，选择已启用的 API，输入作品名，选择作品和剧集。
加载成功后替换当前视频弹幕；失败保留原弹幕。不会自动搜索或上传视频信息。
请求仅包含用户输入的搜索词与所选作品/剧集 ID，不发送 Emby 令牌。

使用的端点：
- `GET /api/v2/search/anime?keyword=…` → `animes[].animeId/animeTitle`
- `GET /api/v2/bangumi/{animeId}` → `bangumi.episodes[].episodeId/episodeTitle`
- `GET /api/v2/comment/{episodeId}?format=json` → `comments[].p/m`

JSON 的 `p` 为 `时间,模式,十进制颜色,用户`，不同于 Bilibili XML 的字段顺序。
仍受 16 MB / 50000 条限制，HTTP 错误和无效数据明确提示；退出搜索页取消请求。
API 地址保存在本机 UserDefaults；路径中的令牌不展示在列表中，不写入播放日志。

已人工验证顺影服务的搜索、作品详情和弹幕响应。没有使用自动匹配接口，避免跨来源/季集误配。

## 常用显示设置

全局设置和播放界面使用相同的持久化设置，即时更新：
- 显示开关、14–40 字号、10%–100% 不透明度、原色/白色、粗体、文字阴影。
- 显示区域：顶部 1/4、1/2、3/4 或全屏；低/中/高密度；0.5–2 倍弹幕速度。
- 滚动、顶部固定、底部固定类型可分别关闭。
- 底部字幕避让默认开启，预留底部 100pt，不依赖引擎字幕内容检测。
- 屏蔽关键词按包含关系匹配，不区分大小写，支持换行、逗号、分号分隔。
- 重复过滤默认开启，10 秒内的相同文字不重复显示。

速度按媒体时间计算，固定弹幕停留时间也随之调整。显示区域从顶部开始，底部固定弹幕放在该区域最下方。所有类型共享空闲轨道，避免相互遮挡。
恢复默认设置需要确认，不清除已加载弹幕、API 或当前视频偏移。
布局测试覆盖区域、密度、速度、类型、关键词、重复过滤及字幕避让边界。
