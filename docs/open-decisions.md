# 待决事项

下列问题会影响产品、架构或验收，应在相关功能进入实现前确认。未决事项不应被写成既定功能承诺。

| 事项 | 需要确认的选择 | 当前约束 / 影响 |
|---|---|---|
| 最低 iOS 版本 | 当前构建基线为 iOS 26，正式最低版本待确认 | 首发平台已确定仅 iOS（iPhone），不包含 iPadOS、macOS、tvOS。 |
| 最低系统版本 | 各首发平台的 deployment target | 影响 Swift API、系统播放器能力和测试矩阵。 |
| 标签栏交互验收 | 在设备上验证默认隐藏、多任务按钮切换和点击内容收起 | 采用系统 TabView/Tab 的可见性 API，不自绘标签栏或强制向左展开。 |
| 本地媒体入口 | 系统文件选择器、应用导入、媒体资料库或其他 | 决定权限、文件访问句柄和库管理方式。 |
| 在线媒体范围 | 直链、HLS/DASH、播放列表、NAS/网络协议等 | “在线支持”不等同于支持所有协议；需按用户需求排序。 |
| 在线内容边界 | 用户自有/授权内容及允许的来源类型 | 需明确内容合规、安全和凭据处理要求。 |
| 个性化首版范围 | 主题、手势、字幕/音轨偏好、播放默认值、收藏等 | 决定设置模型和首版信息架构。 |
| Trakt 集成范围 | 登录、观看进度同步、收藏/列表或资料关联等具体范围 | 已确认目标服务为 Trakt；API、OAuth、数据同步方向、冲突处理和隐私要求仍需确认。 |
| IMDb 对接方式 | 确认使用何种 API/数据源、许可和归因要求 | IMDb 品牌/数据使用和 API 可用性需先核实；不默认存在可自由使用的官方 API。 |
| 媒体匹配策略 | 自动匹配、人工确认阈值、多个结果的处理 | 错误匹配不得静默覆盖用户已有信息。 |
| 常用播放器设置 | 确认首版必需选项与分组 | 仅呈现 KSPlayer、目标平台和当前媒体实际支持的设置。 |
| PiP 后端验证 | 确认 KSPlayer 后端、视频渲染路径及 PiP/远程命令支持 | PiP、暂停/继续和跳转列为需求；须在目标 OS/设备实测，不能只依据框架描述推定可行。 |
| 紧凑播放条细节 | 确认显示位置、信息密度及关闭/停止行为 | 已确定收缩到应用标题/导航区域，不做 App 内可拖动小窗；布局仍需按平台验证。 |
| 历史与同步 | 仅本地记录、跨设备同步或不保存 | 影响隐私告知、账户和后端需求。 |
| KSPlayer 许可 | GPL 合规使用或申请其他授权 | 在分发方式和商业模式明确前不得推定可用许可。 |
| 品牌与视觉 | 产品名称、标识、色彩、字体和无障碍 token | 视觉规范当前先定义行为原则，待品牌方向确认后补全。 |

确认决策时，将表格中的事项移入对应规范，记录结论、日期和影响；不适用的事项可标注原因后关闭。
